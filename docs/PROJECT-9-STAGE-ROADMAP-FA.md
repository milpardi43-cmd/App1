## محدودیت‌ها و تصمیم‌های ثابت

- Foundation انگلیسی دقیقاً ۱۰ درس × ۵۰ مثال بماند.
- Survival انگلیسی دقیقاً ۱۹ درس × ۵۰ مثال بماند.
- درس‌ها، شناسه‌ها، مثال‌ها و ترتیب نسبی Communication حفظ شوند.
- برای افزودن محتوای انگلیسی/آلمانی از تکرار برای پُرکردن حجم استفاده نشود؛ مثال‌ها روان، مفید و متصل به واژگان باشند.
- در صورت تغییر محتوای آلمانی، مثال‌ها، شناسه‌ها و ترتیب A1 و مثال‌های اصلی A2/B1 حفظ شوند؛ برچسب‌ها گواهی رسمی CEFR نیستند.
- صفحهٔ انتخاب زبان بر پایهٔ فارسی راست‌چین باشد و جزئیات لازم برای انگلیسی و آلمانی را پوشش دهد.
- تجربهٔ صفحهٔ خانهٔ انگلیسی لوکس و حرفه‌ای بماند و صفحهٔ آلمانی نیز طراحی اختصاصی و حرفه‌ای داشته باشد.
- تغییرات نامرتبط workspace حفظ شوند. پکیج مرورگر نصب نشود؛ Chromium نصب‌نشده بماند.
- ابتدا قابلیت‌ها و محتوای بازبینی‌شدهٔ موجود استفاده شوند؛ از ساخت کار تکراری پرهیز شود.

## گزارش پیشرفت مرحلهٔ ۲ — ۱۱ اکتبر ۲۰۲۶

- انگلیسی: `validate:content`، `validate:english-engine`، `validate:english-four` و `validate:english-supplement` همگی موفق شدند. شمار فعلی ۱۷۴ درس/۳٬۸۶۲ مثال است؛ Foundation برابر ۱۰×۵۰، Survival برابر ۱۹×۵۰، Communication برابر ۱۵×۵۰ با هشت واحد موضوعی و پوشش ۵۰۴/۵۰۴ است.
- آلمانی: `validate:german-levels` با ۹۸۳ بررسی و `validate:a1` با ۹۲۱ بررسی موفق شدند. کاتالوگ همچنان ۹۵ درس/۴٬۷۵۰ مثال است. این‌ها آزمون ساختار/رگرسیون‌اند، نه تأیید مستقل مدرس.
- اصلاح هدفمند شش نمونهٔ انگلیسی Advanced انجام شد: ترجمهٔ طبیعی‌تر و واژگان متناسب‌تر برای شناسه‌های `advanced-canonical-practice-72-practice-1` و `advanced-canonical-practice-127-{maintain,snub,wrath,practice-1,practice-2}`. شناسه‌ها و متن انگلیسی دست‌نخورده ماندند؛ برای این نمونه‌ها آزمون رگرسیون اضافه شد.
- هیچ تغییر محتوایی در Foundation، Survival یا Communication انجام نشد.
- بازبینی مستقل مدرس و تجربهٔ واقعی زبان‌آموز را خودکار/انجام‌شده تلقی نمی‌کنیم. برای A1 آلمانی بستهٔ ثبت بازخورد انسانی در `docs/A1-REVIEW-KIT-FA.md` موجود است؛ این مورد به شواهد واقعی نیاز دارد.

## گزارش پیشرفت مرحلهٔ ۳ — بهبود انگلیسی

- ممیزی Advanced: ۱۱۰ درس و ۶۶۲ مثال؛ ۱۰۸ درس ۶مثالی و دو درس ۷مثالی. هر ۶۶۲ متن انگلیسی یکتا است؛ ترجمهٔ فارسی، واژه و راهنمای تلفظ خالی پیدا نشد.
- جست‌وجوی پیوند واژه در مثال‌ها ۱۳ مورد بدون تطابق ظاهری پیدا کرد. هشت مورد اصلاح شد: `farm-share`، `route-together`، `behavior-calm`، `biography-lesson`، `court-answer`، `wholesale-review`، `safety-report` و `sample-repeat`. پنج مورد باقی‌مانده پس از بررسی، شکل صرفی یا فعل عبارتیِ درست‌اند (`keep everyone away`، `signifies`، `unified`، `knelt`، `receding`).
- هر ۱۱۰ گفت‌وگوی Advanced نیز بررسی شد؛ ۱۱۰ الگوی گفت‌وگوی یکتا و بدون تکرار عینی پیدا شد.
- `validate:content` اکنون یکتایی شناسه و متن انگلیسی Advanced و کامل‌بودن متن/ترجمه/تلفظ/واژهٔ هر مثال را نیز کنترل می‌کند؛ شمار مشخصی را قفل نمی‌کند تا گسترش آینده مانع نداشته باشد.
- شناسه‌ها و ترتیب درس‌ها حفظ شده‌اند؛ چند جملهٔ هدفمند برای ارتباط روشن‌تر با واژهٔ درس بازنویسی شدند. هیچ مثال تکراری اضافه نشد.
- این ممیزی نیازِ کم‌حجمی Advanced را آشکار می‌کند، اما افزودن حدود ۴٬۸۳۸ مثال برای رسیدن مکانیکی به ۵۰ نمونه در هر درس، بدون هدف محتوایی و بررسی یکتایی انجام نمی‌شود. گسترش بعدی باید بر شکاف واقعی و محتوای غیرتکراری تکیه کند.
- Foundation و Survival شمار ثابت خود را حفظ کرده‌اند؛ هیچ محتوایی از Communication در این مرحله تغییر نکرده است.
- آزمون مکمل انگلیسی به‌جای مقایسهٔ بایت‌به‌بایت فایل‌های دورهٔ اصلی با HEAD، اکنون جدایی واقعیِ شناسه‌ها و کلید ذخیره‌سازی supplement را می‌سنجد؛ بنابراین اصلاح مجاز در Advanced با آزمون «مکمل جداست» تعارض کاذب ایجاد نمی‌کند.

## وضعیت آزمون‌های آخر

- `npm run validate:content`: موفق؛ ۱۴ نمونهٔ بازبینی‌شده، شمارها و شناسه‌ها حفظ.
- `npm run validate:german-levels`: موفق؛ ۹۸۳ بررسی.
- `npm run validate:a1`: موفق؛ ۹۲۱ بررسی، بدون ادعای بازبینی انسانی.
- `npm run validate:english-engine`: موفق؛ ۲٬۴۳۵ بررسی.
- `npm run validate:english-four`: موفق؛ ۲٬۱۰۳ بررسی.
- `npm run validate:english-supplement`: موفق؛ ۱٬۸۷۲ بررسی.
- `npm run typecheck`: موفق.
- `npm run validate:logic`: ۱٬۶۳۸ بررسی موفق، صفر خطا.
- مسیرهای `/learn/de` و `/learn/de/backup`: پاسخ HTTP 200 در پیش‌نمایش.
- آزمون بصری مرورگر اجرا نشده است؛ Chromium نصب نشده و نصب هم نخواهد شد.

## گام ادامه

کار داخلیِ مرحلهٔ ۲ (ممیزی قابل‌انجام در مخزن و اصلاح خطاهای روشن) تکمیل شد. تأیید مستقل مدرس/زبان‌آموز به‌عنوان دروازهٔ انسانی مرحلهٔ ۹ باز می‌ماند و نتیجهٔ جعلی ثبت نمی‌شود. مرحلهٔ فعال اکنون **۳: بهبود انگلیسی** است. زیرگام بعدی: نقشهٔ موضوعی/مهارتی Advanced را بررسی و فقط شکاف‌های واقعی را اولویت‌بندی کنیم؛ هر توسعه باید به‌صورت دستهٔ کوچک و غیرتکراری باشد و شناسه‌ها/مثال‌های قبلی را حفظ کند. افزودن مکانیکی جمله برای رسیدن به عدد ۵۰ انجام نشود.
